# GLOWLIPI AI - Multilingual Beauty Product Recommendation

## Objective
To recommend beauty products based on Hinglish/Marathi/English text using NLP TF-IDF.

## Folder Structure (As per Guidelines)
- dataset/products.csv : 100+ products data
- source_code/app.py : main recommendation logic
- notebooks/ : EDA and experiments
- output/ : results
- screenshots/ : project screenshots
- requirements.txt : dependencies
- README.md : Documentation

## How to Run
pip install -r requirements.txt
python source_code/app.py

## Model Used
TF-IDF + Cosine Similarity

## Sample
Input: "mera face oily hai"
Output: Minimalist Niacinamide Serum
